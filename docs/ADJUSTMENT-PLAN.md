## 二、排行显示问题（已用线上数据实锤）

### 问题 1：性价比榜被弱模型霸榜 ❗（最严重）

当前公式「性价比 = 能力分 ÷ 混合价」，分母越小数值越高，导致：

- **前 10 名中 7 个能力分 < 60**（满分 100）：
  - 第 1 名 ling-3.0-flash-vl（能力 42.7 分）
  - 第 6 名 gpt-oss-20b（能力 **15.6** 分）
- **前 30 名中 70%（21 个）能力分 < 50**

→ 用户看到的"性价比排行榜"实际上是个"便宜但弱"榜，名不副实。

### 问题 2：最便宜榜混着无评分 / 0 分模型

- 第 1 名 mistral-nemo **无评分**（显示"—"）
- 第 3 名 ling-3.0-flash 能力分 **0**、第 8 名 llama-3.1-8b 能力分 **0**
- 前 10 中 6 个无评分或 0 分

→ 榜单上大量"—"和 0 分，看起来像坏了。

### 问题 3：无评分模型占了 62%

全库 341 个模型，只有 131 个（38%）有第三方评分。榜单、象限图、排名提示在"无评分"模型上表现不一致（有的排最前、有的消失、有的显示"—"）。

### 修复方案（三选一，见决策点 Q1）

- **方案 A｜榜单加能力门槛**：所有榜单默认只排"能力分 ≥ 60"的模型，旁边放"显示全部"开关。最简单直接。
- **方案 B｜首页主榜换成"效率前沿"榜**：只展示帕累托最优模型（同等价格能力最强、同等能力价格最低的那一条线），天然过滤弱模型，榜单质量最高。
- **方案 C｜A+B 组合（我的推荐）**：首页主榜 = 效率前沿榜；次榜 = 性价比榜但加能力门槛；无评分模型不进任何榜单（表格页仍可查到，标注"未评分"）。

## 三、结构调整方案

### 现状：6 个页面，首页过载

首页现在堆了：hero 统计 → 数据说明条 → 混合比例滑块卡 → 超长筛选栏 → 性价比定义长说明 → 12 张性价比卡 → 象限图+图例 → 能力榜 → 最便宜榜 → **51 张厂商入口卡片** → 页脚。一屏放不下，滚动 5 屏以上。

### 调整后（推荐）

| 页面 | 调整 |
|---|---|
| **首页** | 精简为 4 段：① hero（标题+4 个核心数字）② 效率前沿主榜（8 张卡）③ 象限图 ④ "按场景快速选"三个入口卡（预算优先 → 跳表格页按价格排序；能力优先 → 跳能力榜；算成本 → 跳计算器）。**51 张厂商卡片、双表格、长说明全部移出首页** |
| **全部模型页** | 保留主表格；厂商入口卡片移到这里底部（或独立"厂商"区块，见 Q4）；筛选栏精简（见 Q3） |
| **对比页** | 不变 |
| **计算器页** | 不变 |
| **方法论页** | 吸收首页移出的"性价比定义、数据来源"等长说明，首页只留一句话+链接 |
| **模型详情页** | 不变 |

页面总数不变（6 个），导航不变。变的只是**首页从"大杂烩"变成"主榜 + 象限图 + 三个场景入口"**。
